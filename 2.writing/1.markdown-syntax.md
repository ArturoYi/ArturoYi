## 标题

使用标题来介绍主要部分。它们构建您的文档并帮助用户浏览内容。

::code-preview
---
class: "[&>div]:*:my-0"
---
## 标题

#code
```mdc
## 标题
```
::

### 副标题

使用副标题进一步划分部分。它们创建更详细的内容层次结构，以提高可读性。

::code-preview
---
class: "[&>div]:*:my-0"
---
### 副标题

#code
```mdc
### 副标题
```
::

::tip
每个标题和副标题都会创建一个锚点，并自动显示在目录中。
::

## 文本格式

Docus 支持大多数 Markdown 格式选项。

| 样式 | 用法 | 结果 |
| --- | --- | --- |
| 粗体 | `**bold**` | **粗体** |
| 斜体 | `*italic*` | *斜体* |
| 删除线 | `~~strike~~` | ~~删除线~~ |

组合格式可以实现更丰富的文本样式和视觉强调。

| 样式 | 用法 | 结果 |
| --- | --- | --- |
| 粗斜体 | `**_bold italic_**` | ***粗斜体*** |
| 粗体删除线 | `~~**bold**~~` | ~~**粗体**~~ |
| 斜体删除线 | `~~*italic*~~` | ~~*斜体*~~ |

## 链接

链接连接文档的不同部分和外部资源，这对于用户导航和提供参考至关重要。
要创建链接，请将链接文本用方括号 `[]()` 包裹。

::code-preview
---
class: "[&>div]:*:my-0"
---
[Nuxt UI](https://ui.nuxt.com/getting-started/installation/nuxt)

#code
```mdc
[Nuxt UI](https://ui.nuxt.com/getting-started/installation/nuxt)
```
::

### 内部链接

对于文档内部链接，请使用根相对路径，例如 `/guide/installation`。

::code-preview
---
class: "[&>div]:*:my-0"
---
[安装](/guide/installation)

#code
```mdc
[安装](/guide/installation)
```
::

## 列表

以结构化、可读的格式组织相关项目。Markdown 支持无序、有序和嵌套列表，以满足各种内容需求。

### 无序列表

无序列表用于没有特定顺序的项目。每个项目以 `-` 符号开头。

::code-preview
---
class: "[&>div]:*:my-0"
---
- 我是一个列表项。
- 我是另一个列表项。
- 我是最后一个列表项。

#code
```mdc
- I'm a list item.
- I'm another list item.
- I'm the last list item.
```
::

### 有序列表

当项目顺序很重要时，例如过程中的步骤，请使用有序列表。每个项目以数字开头。

::code-preview
---
class: "[&>div]:*:my-0"
---
1. 我是一个列表项。
2. 我是另一个列表项。
3. 我是最后一个列表项。

#code
```mdc
1. I'm a list item.
2. I'm another list item.
3. I'm the last list item.
```
::

### 嵌套列表

创建具有子项目的分层列表，以实现复杂的结构。子项目缩进四个空格以进行嵌套。

::code-preview
---
class: "[&>div]:*:my-0"
---
- 我是一个列表项。
  - 我是一个嵌套列表项。
  - 我是另一个嵌套列表项。
- 我是另一个列表项。

#code
```mdc
- I'm a list item.
  - I'm a nested list item.
  - I'm another nested list item。
- I'm another list item。
```
::

## 表格

以清晰的方式呈现行和列中的结构化数据。表格非常适合比较数据或列出属性。

::code-preview
---
class: "[&>div]:*:my-0 [&>div]:*:w-full"
---
| 属性 | 默认值 | 类型 |
| --- | --- | --- |
| `name` | | `string` |
| `size` | `md` | `string` |
| `color` | `neutral` | `string` |

#code
```mdc
| Prop    | Default   | Type                     |
|---------|-----------|--------------------------|
| `name`  |           | `string`{lang="ts-type"} |
| `size`  | `md`      | `string`{lang="ts-type"} |
| `color` | `neutral` | `string`{lang="ts-type"} |
```
::

## 块引用

突出显示重要的引语、引用或强调文本。块引用在视觉上区分引用的内容。

### 单行

单行块引用最适合简短、有影响力的引语或引用，这些引语或引用适合单行。要创建单行块引用，请在段落前面添加 `>`。非常适合简短而有影响力的引语。

::code-preview
---
class: "[&>div]:*:my-0"
---
> Nuxt UI 是 Vue 组件、可组合项和实用程序的集合，以结构和布局为导向，旨在用作应用程序的构建块。

#code
```mdc
> Nuxt UI is a collection of Vue components, composables and utils, oriented on structure and layout and designed to be used as building blocks for your app.
```
::

### 多行

多行块引用适用于较长的引语，或者当您需要在单个引语中包含多个段落时。

::code-preview
---
class: "[&>div]:*:my-0"
---
> Nuxt UI 是 Vue 组件、可组合项和实用程序的集合，以结构和布局为导向，旨在用作应用程序的构建块。
>
> 使用 Nuxt UI 创建美观、响应迅速且易于访问的 Vue 应用程序。

#code
```mdc
> Nuxt UI is a collection of Vue components, composables and utils, oriented on structure and layout and designed to be used as building blocks for your app.
>
> Create beautiful, responsive, and accessible Vue applications with Nuxt UI.
```
::
