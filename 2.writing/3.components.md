散文组件是 HTML 排版标签的替代品。它们提供了一种在使用 Markdown 时自定义 UI 的简单方法。

**Docus 和 Nuxt UI** 提供了一套风格化且美观的散文组件，可帮助您使用 [MDC 语法](https://content.nuxt.com/docs/files/markdown#mdc-syntax) 编写文档。

::note{to="https://ui.nuxt.com/getting-started"}
此页面仅突出显示最适合编写文档的散文组件。但是，您可以在 Markdown 中使用**任何 Nuxt UI 或 Nuxt UI 组件**。有关可用组件的完整列表，请访问 Nuxt UI 文档。
::

### `Callout` (标注)

在 `callout` 组件的默认插槽中使用 markdown 为您的内容添加引人注目的上下文。

使用 `icon` 和 `color` 属性自定义它。您还可以传递来自 [`<NuxtLink>`](https://nuxt.com/docs/api/components/nuxt-link) 组件的任何属性。

您还可以使用带有预定义图标和颜色的 `note`、`tip`、`warning` 和 `caution` 快捷方式。

::tabs
  :::tabs-item{.my-5 icon="i-lucide-eye" label="预览"}
    ::::div{.flex.flex-col.gap-4.w-full}
      :::::note{.w-full.my-0}
      这是一些附加信息。
      :::::
    
      :::::tip{.w-full.my-0}
      这是一个有用的建议。
      :::::
    
      :::::warning{.w-full.my-0}
      执行此操作时请小心，因为它可能会产生意外结果。
      :::::
    
      :::::caution{.w-full.my-0}
      此操作无法撤消。
      :::::
    ::::
  :::

  :::tabs-item{icon="i-lucide-code" label="代码"}
  ```mdc
  ::note
  这是一些附加信息。
  ::
  
  ::tip
  这是一个有用的建议。
  ::
  
  ::warning
  执行此操作时请小心，因为它可能会产生意外结果。
  ::
  
  ::caution
  此操作无法撤消。
  ::
  ```
  :::
::

### `Card` (卡片) 和 `CardGroup` (卡片组)

在 `card` 组件的默认插槽中使用 markdown 突出显示您的内容。

使用 `title`、`icon` 和 `color` 属性自定义它。您还可以传递来自 [`<NuxtLink>`](https://nuxt.com/docs/api/components/nuxt-link) 的任何属性。

使用 `card-group` 组件包装您的 `card` 组件，将它们分组到网格布局中。

      icon: i-simple-icons-github
      target: _blank
      title: 仪表盘
      to: https://github.com/nuxt-ui-templates/dashboard
      ---
      一个多列布局的仪表盘。
      :::::
    
      :::::card
      ---
      icon: i-simple-icons-github
      target: _blank
      title: SaaS
      to: https://github.com/nuxt-ui-templates/saas
      ---
      一个包含着陆页、定价、文档和博客的模板。

      :::::card
      ---

### `Collapsible` (可折叠)

使用 `collapsible` 组件包装您的内容，以在您的内容中显示一个 [可折叠](https://ui.nuxt.com/components/collapsible)。

::tabs
  :::tabs-item{.my-5 icon="i-lucide-eye" label="预览"}
    ::::collapsible
    | 属性    | 默认值   | 类型     |
    | ------- | --------- | -------- |
    | `name`  |           | `string` |
    | `size`  | `md`      | `string` |
    | `color` | `neutral` | `string` |
    ::::
  :::

  :::tabs-item{icon="i-lucide-code" label="代码"}
  ```mdc
  ::collapsible
  
  | 属性    | 默认值   | 类型                     |
  |---------|-----------|--------------------------|
  | `name`  |           | `string`{lang="ts-type"} |
  | `size`  | `md`      | `string`{lang="ts-type"} |
  | `color` | `neutral` | `string`{lang="ts-type"} |
  
  ::
  ```
  :::
::

### `Field` (字段) 和 `FieldGroup` (字段组)

`field` 是要在您的内容中显示的属性或参数。您可以通过 `field-group` 将它们分组到一个列表中。

::tabs
  :::tabs-item{.my-5 icon="i-lucide-eye" label="预览"}
    ::::field-group{.my-0}
      :::::field{name="analytics" type="boolean"}
      默认为 `false` - 为您的项目启用分析 (即将推出)。
      :::::
    
      :::::field{name="blob" type="boolean"}
      默认为 `false` - 启用 blob 存储以存储静态资产，例如图像、视频等。
      :::::
    
      :::::field{name="cache" type="boolean"}
      默认为 `false` - 启用缓存存储以使用 Nitro 的 `cachedEventHandler` 和 `cachedFunction` 缓存您的服务器路由响应或函数。
      :::::
    
      :::::field{name="database" type="boolean"}
      默认为 `false` - 启用 SQL 数据库以存储您的应用程序数据。
      :::::
    ::::
  :::

  :::tabs-item{icon="i-lucide-code" label="代码"}
  ```mdc
  ::field-group
    ::field{name="analytics" type="boolean"}
      默认为 `false` - 为您的项目启用分析 (即将推出)。
    ::
  
    ::field{name="blob" type="boolean"}
      默认为 `false` - 启用 blob 存储以存储静态资产，例如图像、视频等。
    ::
  
    ::field{name="cache" type="boolean"}
      默认为 `false` - 启用缓存存储以使用 Nitro 的 `cachedEventHandler` 和 `cachedFunction` 缓存您的服务器路由响应或函数。
    ::
  
    ::field{name="database" type="boolean"}
      默认为 `false` - 启用 SQL 数据库以存储您的应用程序数据。
    ::
  ::
  ```
  :::
::

### `Steps` (步骤)

使用 Steps 组件包装您的标题以显示步骤列表。

使用 `level` 属性定义哪个标题将用于步骤。

::tabs
  :::tabs-item{.my-5 icon="i-lucide-eye" label="预览"}
    ::::steps{level="4"}
    #### 启动一个全新的项目
    
    ```bash [Terminal]
    npm create nuxt@latest -- -t github:nuxt-content/docus
    ```
    
    #### 运行 docus CLI 来启动您的开发服务器
    
    ```bash [Terminal]
    docus dev
    ```
    ::::
  :::

  :::tabs-item{icon="i-lucide-code" label="代码"}
  ````mdc
  ::steps{level="4"}
    #### 启动一个全新的项目
    
    ```bash [Terminal]
    npm create nuxt@latest -- -t github:nuxt-content/docus
    ```
    
    #### 运行 docus CLI 来启动您的开发服务器
    
    ```bash [Terminal]
    docus dev
    ```
  ::
  ````
