## Markdown

使用标准 Markdown 语法显示图片或视频。

### 图片

::code-preview
![Nuxt 社交图片](https://nuxt.com/new-social.jpg)

#code
```mdc
![Nuxt Social Image](https://nuxt.com/new-social.jpg)
```
::

或者使用本地图片

::code-preview
![日落时云海中的雪山](/mountains.webp)

#code
```mdc
![Snow-capped mountains in a sea of clouds at sunset](/mountains.webp)
```
::

::note{to="https://image.nuxt.com/"}
Docus 将在底层使用 `<NuxtImg>` 组件，而不是原生的 `img` 标签。
::
