虽然这件事 AI一句话就可以搞定，但是我们还是自己捣鼓一下。环境还是 **Xcode >= 16.5**。

启动图上不能跑代码，也不能做动画。首帧画出来之后，系统就把它撤掉。

## 先选一种做法

iOS 14 之后有两种方法可以设置启动图。

| 做法 | 介绍 |
| --- | --- |
| `UILaunchScreen` | `Assets` 静态启动图 |
| `LaunchScreen.storyboard` | 苹果推荐：LaunchScreen.storyboard（**一套图适配所有 iPhone/iPad，自动布局**） |

## storyboard

在创建传统Storyboar项目时，项目中默认会有`LaunchScreen.storyboard`。

### 配置启动图

在Storyboar项目中，在`project.pbxproj`文件中默认带了下面配置：

```Swift
INFOPLIST_KEY_UILaunchStoryboardName = LaunchScreen;
INFOPLIST_KEY_UIMainStoryboardFile = Main;
```

工程默认开了 `GENERATE_INFOPLIST_FILE = YES`，这个键会写进最终的 `Info.plist`，对应系统读的 `UILaunchStoryboardName`。

同时，你也可以手动配置，只需要在`Info.plist`里添加下面配置：

::steps{level="4"}
#### 打开 General

选中项目 Target，切到 **General**。

#### 找到启动图设置

在 **App Icons and Launch Images** 里定位 **Launch Screen File**。

#### 选择启动图文件

下拉选择 `LaunchScreen.storyboard`，注意文件名称默认是`LaunchScreen`，注意空格。
::

::note
Xcode 在 `Info.plist` 写入 `UILaunchStoryboardName = LaunchScreen`。
::

```xml
<key>UILaunchStoryboardName</key>
<string>LaunchScreen</string>
```

手动声明会覆盖`INFOPLIST_KEY_UILaunchStoryboardName`,打包时会把这份 plist 和其余自动生成的键合并，不用额外处理，但如果遇到如果不生效可以删除此配置。

### 在画布和源码之间切换

`LaunchScreen.storyboard` 可以当画布拖，也可以当 XML 改。在左侧项目导航器里右键这个文件，选 **Open As**：

- **Interface Builder**：可视化画布，拖控件排版。双击文件时默认打开这个
- **Source Code**：底层 XML。要整段复制 storyboard 时用这个

### 纯色背景，Logo 居中

`LaunchScreen.storyboard` 常见两种排法。先写分层的这种：纯色打底，Logo 摆在中间，一套约束适配各种屏幕。后面那种只放一张图，四边铺满，大多数人用那种。

根 View 是一层纯色，上面再叠一个 Image View。换设备时父视图变大变小，Logo 仍停在正中，不用为每台机器各做一张图。

::steps{level="4"}
#### 准备 Logo

在 `Assets.xcassets` 里新建 Image Set，命名为 `LaunchLogo`。矢量用 PDF，并勾选 **Preserve Vector Data**。位图则放上 @2x 和 @3x。

#### 铺上背景色

打开 `LaunchScreen.storyboard`，选中根 View，在右侧 **Attributes** 里把 **Background** 改成品牌色。选一种固定的 sRGB 颜色。System Background 会跟着系统的浅色、深色切换。

#### 放入 Logo

从对象库拖一个 **Image View** 到画布上。**Image** 选 `LaunchLogo`，**Content Mode** 选 **Aspect Fit**。

#### 用约束适配各种屏幕

选中这个 Image View，用画布底部的约束按钮：

1. **Add New Constraints**：宽度、高度填 Logo 的点尺寸，例如 `120` 和 `120`
2. **Align**：勾选 **Horizontally in Container**、**Vertically in Container**

居中是相对父视图算的。点画布底部 **View as**，在 iPhone SE、大屏 iPhone、iPad 之间切换，Logo 应始终在屏幕正中，点尺寸不变。横屏同样成立。

iPad 上需要更大的 Logo 时，选中宽度约束，在 **Constant** 右侧点 **+**，为 **Width: Regular** 填一个更大的数。高度同样加一条。Logo 是正方形时，改成宽高 1:1 的比例约束，只改宽度即可。
::

::note
启动图里只用 `UIView`、`UIImageView`、`UILabel`。自定义类和 outlet 在这里不会执行。要在 Logo 下面加应用名，再拖一个 Label，水平居中，顶部贴住 Logo 的底部。
::

画布排完之后，也可以右键文件，**Open As → Source Code**，整份替换成下面的 XML。背景色和 `120` 换成自己的数，`LaunchLogo` 要和 Image Set 的名字一致。

### 一张图铺满

大多数人只放一张图：四边贴在根 View 上，**Content Mode** 用 **Aspect Fill**，屏幕比例对不上的部分裁掉。

::steps{level="4"}
#### 按最大屏幕出图

图要盖住最大的那块屏。只做 iPhone 时，竖屏至少按 Pro Max 的尺寸出。还要上 iPad，就按 iPad 的画布出。主体和文字留在画面中间，四周留出可以被裁掉的边。

放进 `Assets.xcassets`，命名为 `LaunchBackground`。单张太大时，Xcode 会提示启动图超出内存限制，启动时变成黑屏，把图压小再放进去。

#### 四边约束到父视图

拖一个 **Image View** 盖住根 View，然后：

- **Image** 选 `LaunchBackground`
- **Content Mode** 选 **Aspect Fill**
- 勾选 **Clips to Bounds**
- **Add New Constraints** 里上、下、左、右都填 `0`，取消 **Constrain to margins**。每条边旁边的箭头选根 View（**Superview**）

四边为 `0` 才会铺到状态栏和底部横条后面。选了 Safe Area 的话，刘海和 Home 指示条旁边会露出底色。
::

## UILaunchScreen

## 改了图却还是旧的

启动图会被系统缓存。换了资源，模拟器里往往还是上一张。

按这个顺序清：

1. 在模拟器里删掉 App
2. Xcode 菜单 **Product** → **Clean Build Folder**（`Shift + Cmd + K`）
3. 重新 `Cmd + R`

还是旧图的话，用模拟器菜单 **Device** → **Erase All Content and Settings...**，或者直接重启模拟器。真机上删掉 App 之后，有时还要重启手机。

只换像素、资源名不变时，缓存更顽固。把 Image Set 改个名字，**Info** 或 storyboard 里的引用一起改掉，一般就能看到新图。

## 和第一个界面接上

启动图停留的时间很短。它和根控制器差得太多，中间会闪一下。

底色、Logo 的位置尽量和 `ViewController` 第一帧一样。需要一段品牌动画时，在根控制器里用同一张图当第一帧，等 `viewDidAppear` 再动。动画写在启动图上不会执行。

根控制器怎么挂，还是看 [创建基于 UIKit 的原生 iOS 项目](/blog/create-uikit-ios-project) 里 `SceneDelegate` 那一段。
