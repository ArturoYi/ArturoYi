[fast_package](https://github.com/ArturoYi/fast_package) 是我写的一个 Flutter 工具包。防抖、节流、异步队列、字符串扩展，以及 Toast、Loading、扫光、下拉刷新、侧滑和动画列表，都从这里引。依赖只有 Flutter SDK。

当前版本是 **0.0.6**。Dart SDK 要求 `>=3.3.4 <4.0.0`，Flutter 要求 `>=3.19.6`。Android、iOS、Linux、macOS、Web、Windows 都能用。文档站中文是默认语言，英文在 `/en/`。示例工程编成了网页，可以在浏览器里直接点。站点的 [Flutter 示例](/demos?cat=flutter) 里也能直接打开仓库。

## 项目初衷

几个 Flutter 项目里，同一类代码会反复出现：搜索框要防抖，按钮要节流，上传要一条条排队，列表要下拉刷新、侧滑删除、插入时带一段动画。每接一个第三方包，就要跟着它的版本和传递依赖走。这些能力用 Flutter SDK 就能写清楚。

这个包把它们收在一处。公共 API 尽量手写，源码可以直接读，用到哪个模块就看哪一段。安装、参数和完整示例以[在线文档](https://arturoyi.github.io/fast_package/)为准。

## 它做了什么

0.0.6 已经能盖住日常列表页和全局反馈。主题都走 `ThemeExtension`，文案和颜色可以跟应用主题一起换。

### 工具方法

- **频率控制**。`FastDebounce` 在静默期结束后只跑最后一次，适合搜索联想。`FastThrottle` 在一个时间窗里最多执行一次，适合提交和点赞。`FastRateLimit` 第一次立刻执行，窗内后续调用合并成下一次再跑。三者都用 `tag` 区分场景，页面销毁时按 tag 取消。
- **异步队列**。`FastAsyncQueue` 按 FIFO 串行执行。可以先攒任务再 `start()`，也可以 `autoStart()`，来一条处理一条，同一时刻仍然只有一个任务在跑。任务可以带 label，失败后在任务里 `retry()`。
- **扩展**。字符串的驼峰、蛇形、短横线转换，以及空安全的默认值。`num` 上有区间和整除判断。
- **Cover 尺寸**。`fastCoverScanSize` 和 `fastCoverScanScale` 按 CSS `object-fit: cover` 的算法，算出铺满容器所需的尺寸或缩放。图片本身继续用 `BoxFit.cover`。

### 界面组件

- **Toast**。根上挂 `FastToastOverlay` 之后，`showToast` 不需要 `BuildContext`。同一时刻一条，其余按 FIFO 排队，等待上限 5 条。
- **Loading**。`showLoading` 同样不需要 context，始终居中。再次调用会换掉当前这一条。关掉要调用 `FastLoading.dismiss()`。展示期间默认拦住返回。
- **扫光**。`FastShimmerBox`、`FastShimmerText` 这些积木用来手写骨架。`FastShimmerHighlight` 给真实文字和图标打一道细光束。`FastShimmerSlideUnlock` 是可拖动的滑动解锁，拖动时暂停扫光。同一 `FastShimmerScope` 里相位一致。
- **刷新**。`FastRefresh` 自己处理越界和回弹，松手后先吸到触发位再跑任务。默认是 Classic 头尾，也可以换成 Material 指示器。`FastPagingList` 在它上面做分页：给 `fetchPage` 和 `itemBuilder`，空态和没有更多由分页状态管。
- **侧滑**。`FastSlidable` 支持左右或上下滑出操作，滑到底可以删除。`FastSlidableGroup` 让同一组里只展开一行。竖直方向的刷新进行时，侧滑会被锁住。
- **动画列表**。`FastAnimatedList` 根据 `items` 和稳定的 `itemId` 做插入、删除动画，不用手动调 insert 和 remove。只要排序时用 `FastReorderableList`，两样都要时用 `FastAnimatedReorderableList`。首屏错开共用一个 ticker。列表还在滑、或者刷新正在追加尾部时，新行直接到位。
- **渐变边框**。`GradientBoxBorders` 写在 `BoxDecoration.border` 上，矩形、圆角和圆形都能画渐变描边。

列表场景可以叠在一起用：刷新包住动画列表，行内再放侧滑。示例工程里每种组合都有一页。

## 怎么使用

### 安装

到 [pub.dev](https://pub.dev/packages/fast_package) 看最新版本号，再写进 `pubspec.yaml`：

```yaml
dependencies:
  flutter:
    sdk: flutter
  fast_package: ^0.0.6
```

```dart
import 'package:fast_package/fast_package.dart';
```

### 挂上全局反馈

Toast 和 Loading 都挂在 `MaterialApp.builder`。Loading 放在外层，遮罩会盖住 Toast。

```dart
final rootNavigatorKey = GlobalKey<NavigatorState>();

MaterialApp(
  navigatorKey: rootNavigatorKey,
  builder: (context, child) {
    return FastLoadingOverlay(
      navigatorKey: rootNavigatorKey,
      child: FastToastOverlay(
        child: child ?? const SizedBox.shrink(),
      ),
    );
  },
);
```

之后在任意位置：

```dart
showToast('保存成功');

showLoading();
await save();
FastLoading.dismiss();
```

### 控制连点

搜索框停下来再请求：

```dart
FastDebounce.debounce(
  tag: 'search-suggest',
  duration: const Duration(milliseconds: 300),
  onExecute: () => fetchSuggestions(keyword),
);
```

离开页面时调用 `FastDebounce.cancel('search-suggest')`。
