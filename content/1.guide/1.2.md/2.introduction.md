欢迎来到 **ArturoYi**，一个基于 [Nuxt 4](https://nuxt.com) + [Docus](https://docus.dev) + [Nuxt Content](https://content.nuxt.com) 构建的个人技术博客与知识库。

## 项目定位

- **核心用途**：技术笔记、博客文章、知识文档、学习归档
- **视觉标准**：对标 VitePress 经典三栏布局与排版
- **运行模式**：默认 SSG 静态预渲染，极致 SEO

## Frontmatter 规范

每篇文章支持以下 frontmatter 字段：

```yaml
---
title: 文章标题
description: 页面描述（SEO 专用）
order: 1          # 侧边栏排序权重
draft: false      # 草稿不参与导航与发布
sidebar: true     # 是否显示左侧边栏
toc: true         # 是否显示右侧目录
---
```
