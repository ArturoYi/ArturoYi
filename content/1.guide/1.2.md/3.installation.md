## `create-docus` CLI

::steps
### 创建您的文档目录

使用 `create-docus` CLI 创建一个新的 Docus 项目：

```bash [Terminal]
npx create-docus my-docs
```

您可以选择两种模板：

- `default`: 用于单语言文档的基本 Docus 设置
- `i18n`: 包含多语言文档的国际化支持

```bash [Terminal]
# 使用 i18n 模板创建
npx create-docus my-docs -t i18n
```

我们建议使用 `npm` 包管理器。

### 启动您的文档开发服务器

进入您的文档目录并以开发模式启动您的文档服务器：

```bash [Terminal]
cd my-docs
npm run dev
```

您的文档的本地预览将在 <http://localhost:3000> 可用

### 编写您的文档

请参阅 [Markdown 语法](/writing/markdown-syntax) 部分，了解如何编写文档。
::

## 层集成

Docus v4 使用**基于 Nuxt 层的方案**，您可以在 `nuxt.config.ts` 中通过 `extends: ['docus']` 直接扩展 Docus 层：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['docus']
})
```
