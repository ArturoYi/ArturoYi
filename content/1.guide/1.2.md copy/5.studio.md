**Nuxt Studio** 模块是一个基于浏览器的界面，用于在生产环境中直接编辑您的 Nuxt Content 网站。通过 GitHub、GitLab 或 Google 认证访问您已部署的网站，无需任何本地开发工具即可开始管理内容。

::tip{to="https://nuxt.studio/introduction"}
浏览 Nuxt Studio 文档以了解如何安装该模块。
::

:video{controls loop src="https://res.cloudinary.com/nuxt/video/upload/v1767647099/studio/studio-demo_eiofld.mp4"}

**Studio 编辑器**允许您在生产网站上完全通过浏览器管理内容。无需本地开发工具、Git 命令或终端访问。它非常适合希望在熟悉的环境中编辑和预览内容更改的内容团队。

## 您的 Nuxt Content 网站在生产环境中的可视化编辑

Nuxt Studio 为由 Nuxt Content 驱动的网站提供**在生产环境中直接进行可视化编辑**。

Studio 最初作为独立的付费平台提供，现在是一个**免费、开源且可自托管的 Nuxt 模块**。它使您的整个团队，无论是开发人员还是非技术编辑，都可以在不离开您的实时网站的情况下安全地创建和更新内容。

## 当前功能

### ✨ **TipTap 可视化编辑器**

具有完整 MDC 组件支持的富 Markdown 编辑器。

### 💻 **Monaco 代码编辑器**

如果您想编辑原始代码，可用于 Markdown (MDC)、YAML 和 JSON 文件的高级代码编辑器。

### 📝 **基于表单的编辑器**

使用基于集合 schemas 自动生成的表单编辑 YAML、JSON 和 frontmatter。

### 🎨  **Vue 组件 Props 编辑器**

直接从编辑器编辑 Vue 组件 props 的可视化界面。

### 🔄 **实时预览**

立即在您的生产网站上预览内容更改。

### 🔐 **多提供商身份验证**

通过 GitHub、GitLab 和 Google 进行安全的 OAuth 身份验证。

### 🔑 **自定义身份验证**

实现自定义身份验证流程（密码、SSO、LDAP 等）的实用程序。

### 📝 **文件管理**

在 [content/]{.s2} 目录中创建、编辑、重命名和删除内容文件。

### 🖼 **媒体管理**

集中式媒体库，支持 JPEG、PNG、GIF、WebP、AVIF、SVG 等。

### 🌳 **Git 集成**

直接从生产环境提交内容更改，并依靠您的 CI/CD 管道进行部署。

### 🚀 **开发模式**

使用 Studio 界面直接从本地文件系统编辑内容和媒体文件。

### 🌍 **国际化**

全面支持 17 种语言的国际化：AR、BG、DE、EN、ES、FA、FI、FR、ID、IT、JA、NL、PL、PT-BR、UA、ZH、ZH-TW。

## **即将推出的功能**

从统一界面管理和导航所有内容集合。

### 🖼 **媒体优化**

### 🤖**AI 内容助手**

获取智能、AI 驱动的建议，以改进和加快内容创建。
