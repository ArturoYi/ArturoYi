## **从 Docus v3 迁移到 v4**

Docus v4 引入了新的**基于层的方法**，它利用官方的 Nuxt CLI 而不是自定义的 Docus CLI。虽然您现有的内容和配置仍然兼容，但您需要更新您的命令和项目设置。

### **⚠️ 突破性变更**

主要的突破性变更与 CLI 命令有关：

| v3                       | v4                           |
| ------------------------ | ---------------------------- |
| `npx docus init my-docs` | `npx create-docus my-docs`   |
| `docus dev`              | `nuxt dev --extends docus`   |
| `docus build`            | `nuxt build --extends docus` |

::tip
您现有的 Markdown 内容和 MDC 语法无需更改即可使用。迁移主要涉及更新您的开发和构建工作流程。
::

## **迁移到 Docus**

已经在使用基于 Markdown 的解决方案来管理您的文档了吗？无论是 **Docus v1**、**Nuxt UI 文档模板**，还是其他静态网站设置，迁移到 Docus 都简单明了。

Docus 提供了一个干净且易于维护的解决方案，只有一个依赖项：Docus 库本身。无需管理多个依赖项。所有功能都内置并共同维护，使您的文档保持最新比以往任何时候都更容易。

要迁移，只需将您现有的 Markdown 文件移动到 Docus starter 的 `content/` 目录中。

接下来，您有两种情况：

- **如果您的当前文档已经使用 Nuxt Content 和 MDC 语法**，请确保您的内容中使用的组件存在于 Nuxt UI 中。如果缺少任何组件，您可以轻松创建自己的自定义组件。
- **如果您使用的是标准 Markdown**，您可以按原样复制您的文件。然后，使用 Nuxt UI 提供的内置组件逐步增强您的文档。

将内容移动到 `content/` 文件夹后，您可以按照[配置文档](https://docus.dev/concepts/configuration)自定义您的应用程序。

Docus 旨在专注于编写内容，因此如果您已经在使用 Markdown，您可以轻松切换到它。
