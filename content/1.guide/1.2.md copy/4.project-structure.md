## 全局结构

本项目基于 **Nuxt 4 + Docus 层** 构建，遵循 Docus 标准目录规范：

```bash
ArturoYi/
├── content/                # 所有博客/文档 Markdown（核心写作目录）
├── app/                    # 自定义组件、布局、配置
│   ├── app.config.ts       # 站点品牌、SEO、主题配置
│   ├── app.css             # VitePress 风格样式覆盖
│   ├── components/         # 覆盖默认组件
│   └── layouts/            # 布局覆盖
├── config/                 # 项目级配置
├── public/                 # 静态资源、favicon
├── content.config.ts       # 内容集合与 frontmatter schema
├── mdc.config.ts           # MDC 语法、代码高亮配置
└── nuxt.config.ts          # 全局配置（SEO、SSG、模块）
```

## `content/` 目录

Markdown 文件即路由，目录结构自动生成侧边栏导航：

```bash
content/
├── index.md                    # 首页 (/)
├── 1.guide/                    # 指南分类
│   ├── .navigation.yml         # 分类标题与图标
│   ├── 2.introduction.md       # /guide/introduction
│   └── ...
└── 2.writing/                  # 写作示例
    ├── .navigation.yml
    ├── 1.markdown-syntax.md    # /writing/markdown-syntax
    └── ...
```

::tip
数字前缀（如 `1.guide`）用于控制侧边栏排序，可在 frontmatter 中用 `order` 字段微调单页顺序。
::

## Frontmatter 字段

```yaml
---
title: 文章标题
description: 页面描述（SEO）
order: 1
draft: false
sidebar: true
toc: true
---
```

## 部署命令

| 命令 | 用途 |
| --- | --- |
| `pnpm dev` | 开发环境，热更新 |
| `pnpm generate` | SSG 静态打包，输出至 `.output/public` |
| `pnpm preview` | 预览生产构建 |

支持 Vercel、Netlify、GitHub Pages、阿里云 OSS 等静态平台零配置部署。
